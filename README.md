# 养生馆网页系统

面向养生馆/理疗门店的轻量网页系统：用户端展示与在线预约，管理端审核与门店配置。

## 运行

```bash
pip install flask
python app.py            # http://127.0.0.1:5000
python app.py --selftest # 无窗口自检
```

- 管理后台：`/admin/login`，首次启动在控制台打印随机管理员密码
- 数据存储：SQLite（`ysg.db`，首次启动自动建表并写入示例数据）

## 功能

- 客户端：首页展示、项目浏览、在线预约（时段防重复）、短信验证码登录（开发模式验证码直接显示，上线在 `send_sms()` 接短信服务商）、预约查询、个人中心
- 管理端：预约审核、项目/分类/技师/会员管理、门店配置、轮播图上传

## 结构

- `app.py` — 全部后端（Flask + SQLite）
- `templates/` — 页面模板（客户端 + 后台）
- `static/` — 样式、脚本、上传图片

## 注意

- 上线公网前：接入真实短信、加 CSRF 防护、换生产服务器（waitress/gunicorn）
- 修改门店信息：登录后台 →「门店配置」
